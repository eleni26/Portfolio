Did rezoning change what gets built in Calgary?

Azure Data Factory, Azure SQL and Power BI, November 2026

Calgary changed its zoning rules in August 2024 and reversed them in August 2026. I wanted to know whether that changed what actually got built. An Azure Data Factory pipeline pulls all 503,000 building permits from the City's open data into a data lake and then into Azure SQL, where stored procedures clean them and build a star schema for Power BI.

  • New housing units rose 34% during rezoning, from 1,504 to 2,020 a month.
  • Duplexes, townhouses and rowhouses grew 43%, but their share of new homes barely moved, because every other type grew too.
  • The first months after the repeal are still above the old baseline, though it's too early to call.

Sales performance analysis

SQL Server and Power BI, June 2026

The data was deliberately messy: misspelled categories, placeholder phone numbers, impossible dates, and a Region column that didn't match the states. I cleaned it in SQL Server and built a sales fact table with six dimensions.

Along the way I tracked down a $353K gap between the dashboard total and the regional breakdown (blank region values my NULL check missed) and a duplicate relationship that was inflating order counts. The report has a sales overview page and a sales distribution page, with a year slicer.

Customer lifetime value

SQL Server and Power BI, May 2026

Built on AdventureWorks. A T-SQL stored procedure builds the star schema, and Power BI shows lifetime value ($5.75K), average order value ($3.49K) and repeat-purchase rate for more than 19,000 customers.

My first retention number was 86.83%, which looked great and was wrong. It counted customers with more than one order line, not more than one order. The real figure is 39%, and that's what the dashboard shows now.

Whale vs. diversity sales analysis

SQL Server and Power BI

How much of a reseller's revenue rides on a few huge orders? In AdventureWorks, orders over $50K are 13% of the 3,806 reseller orders but bring in 45.5% of the revenue. I built a SQL Server data mart and a Power BI dashboard showing which territories lean on those big orders most: France, Northwest, the UK and Southwest, all above 50%.
